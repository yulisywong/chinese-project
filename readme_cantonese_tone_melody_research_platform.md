# 《粵語流行曲中的聲調與旋律配合》研究問卷與後台管理系統 (HKU CEDU9001)

本專案為香港大學言語治療學生（課程編號：**CEDU9001**）所設計之學術研究問卷平台，旨在探討粵語流行曲中的**聲調與旋律配合（Tone-Melody Alignment）**對聽眾理解及聆聽體驗的影響。

系統參考 Google Forms 的使用體驗設計，分為**公開填寫模式（Published Mode）**與**受密碼保護的編輯與數據分析模式（Admin / Edit Mode）**。

## 🔐 權限與模式說明 (Access Control & Modes)

### 1. 公開模式 (Published Mode) — 供受訪者使用
* **純淨填寫體驗**：受訪者僅能瀏覽並填寫已發布的問卷內容。
* **權限隔離**：隱藏所有編輯按鈕、題目修改介面、數據統計圖表（Dashboard）及原始數據匯出功能，確保研究數據的保密性與問卷結構不被更動。
* **音訊播放限制**：支援按研究設定播放音訊（例如限制每段錄音僅可播放一次）。

### 2. 編輯與數據分析模式 (Edit & Analytics Mode) — 供研究人員使用
* **進入方式**：點擊頁面頂部導覽列的「管理員 / 編輯模式」按鈕，輸入預設密碼即可解鎖。

* **即時編輯器 (Google Forms 風格)**：
  * **上傳本地音訊檔**：支援從電腦或手機直接選取並上傳本地音訊檔案（`.mp3`, `.wav`, `.m4a`, `.ogg` 等）至對應題目或版本比較區塊。

## 📋 問卷架構與內容摘要 (Questionnaire Structure)

本問卷共分為七個核心部分，預計完成時間為 **5–10 分鐘**：

### 第一部分：研究同意書 (Consent Form)
* **研究說明**：香港大學言語治療學生 CEDU9001 學術研究，資料完全匿名且僅作學術用途，參與屬自願性質，可隨時退出。
* **同意確認**：勾選方塊確認已閱讀並同意參與本研究後方可進入下一部分。

### 第二部分：參與者背景資料 (Participant Background)
1. **年齡**：18–20歲 / 21–25歲 / 26–30歲 / 31歲或以上
2. **性別**：男 / 女 / 不願透露 / 其他
3. **母語**：粵語 / 普通話 / 英語 / 其他
4. **自評粵語水平**：1（非常差）→ 7（母語水平）
5. **每週收聽粵語流行曲頻率**：幾乎不聽 / 每月數次 / 每週1–3次 / 每週4–6次 / 每日收聽
6. **正式音樂訓練年資**：沒有 / 1–3年 / 4–6年 / 7年或以上
7. **是否懂得閱讀樂譜**：是 / 否

### 第三部分：聆聽評估 (Listening Task)
* **測試設計**：包含 6 段粵語歌曲錄音（建議配置 3 個 *Tone-Melody Match* 與 3 個 *Tone-Melody Mismatch* 並隨機排序），建議佩戴耳機並依第一印象作答。
* **評估指標（1–7 分制）**：
  1. 這段歌曲聽起來自然嗎？（1 = 非常不自然，7 = 非常自然）
  2. 歌詞與旋律配合程度如何？（1 = 完全不配合，7 = 非常配合）
  3. 歌詞容易理解嗎？（1 = 非常難理解，7 = 非常容易理解）
  4. 歌手的粵語發音自然嗎？（1 = 非常不自然，7 = 非常自然）

### 第四部分：版本比較 (Forced-Choice Comparison)
* **測試設計**：聆聽同一樂句的兩個版本（Audio A 與 Audio B，僅旋律設定不同），於以下四個維度選出較佳版本（選項：`A` / `B` / `沒有明顯差異`）：
  1. 哪個版本較自然？
  2. 哪個版本較容易理解歌詞？
  3. 哪個版本的歌詞與旋律較配合？
  4. 哪個版本比較像專業粵語流行曲？

### 第五部分：歌詞辨認測驗 (Lyric Recognition Task)
* **核心目的**：直接測試 *Tone-Melody Mismatch* 是否影響聽眾對歌詞的準確辨認（共 5–8 題）。
* **題目範例**：
  * **音訊 7**：`風繼續吹` / `東繼續吹` / `通繼續吹` / `空繼續吹`
  * **音訊 8**：`讓愛同行` / `讓你同行` / `讓我同行` / `讓夢同行`

### 第六部分：對歌詞的看法 (Attitudes Toward Lyrics)
* **評估方式**：1（非常不同意）→ 7（非常同意）量表評估以下 6 項陳述：
  1. 我平時聽歌時會留意歌詞內容。
  2. 我認為粵語歌曲應盡量保留原有聲調。
  3. 歌詞比旋律更重要。
  4. 準確的粵語發音會提升歌曲質素。
  5. 即使聲調改變，只要旋律好聽亦沒有問題。
  6. 聲調與旋律不一致時，我會覺得不自然。

### 第七部分：開放式問題 (Open-ended Questions)
1. 你認為一首自然的粵語流行曲應具備什麼特點？
2. 在剛才的錄音中，你有否留意到任何不自然的地方？
3. 你認為歌曲創作時應優先考慮：`歌詞聲調` / `音樂旋律` / `兩者同樣重要`（並附簡述原因欄）。
